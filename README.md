# Starbucks Beverage Nutrition Dashboard ☕

## 📌 Project Overview
This project is a Power BI dashboard that analyzes Starbucks beverage nutrition data. It provides insights into calories, sugar, caffeine, and beverage categories using interactive visualizations.

## 🛠️ Tools Used
- Power BI
- Power Query
- Microsoft Excel

## 📂 Files Included
- starbucks-analysis project.pbix
- starbucks.csv
- directory.csv

## 📊 Dashboard Features
- Total Beverages
- Average Calories
- Average Sugar
- Average Caffeine
- Beverage Category Analysis
- Interactive Charts and KPIs
